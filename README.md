# Конспекты — СПбГУ МКН, НОД/AI360, 2 курс

Конспекты курсов 3-го семестра в LaTeX. Записаны по рукописным конспектам лекций.
Также в конспекте присутствуют добавленные мной пояснения, определения и примеры,
которых на лекциях не было. Такие блоки помечены серой полосой и знаком **(+)** слева.

| Предмет | Папка | Лектор | Готово |
|---|---|---|---|
| Дифференциальные уравнения и динамические системы | `diff_equations/` | Пилюгин С. Ю. | лекции 1–2 |
| Математический анализ | `math_analysis/` | Осипов Н. Н. | лекция 1 |

## Устройство папки предмета

`<предмет>.tex` — главный файл, `<предмет>.pdf` — собранный pdf, `style/` — преамбула по темам, `sections/` — лекции по файлу на каждую, `figures/` — внешние иллюстрации, `templates/` — заготовки блоков (в сборку не входят).
